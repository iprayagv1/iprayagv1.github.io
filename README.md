# Prayag Gangadharan — portfolio

Plain HTML/CSS/JS site, hosted on GitHub Pages.

- **Edit content:** go to `/admin` on the live site and sign in with your GitHub token.
  Every Publish saves a commit to this repo; GitHub Pages updates the site in about a minute.
- **Content files:** `content/site.js` (home page) and `work/data/<case-study>.js` (each case study).
- **Images:** `assets/img/` (home page), `assets/case/<case-study>/` (case study screenshots).
- **Analytics:** GoatCounter, set up from Admin → Analytics.
- **Preview locally:** double-click `index.html`. Open `admin/index.html` and choose
  "Look around without signing in" to try the admin without publishing.
